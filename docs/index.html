地震資料機器學習偵測專案

專案簡介

本專案致力於地震資料的自動化下載、處理與機器學習偵測。
你可以在本倉庫找到相關的 Python 筆記本、資料下載腳本，以及地震資料處理流程。

目錄結構

  • eqt/examples/downloading.ipynb：地震台站資料下載與查詢範例
  • downloads_mseeds/：下載的地震原始資料
  • json/station_list.json：台站清單 JSON 檔案
  • ModelsAndSampleData/：模型與範例資料

快速開始

  1. 打開 eqt/examples/downloading.ipynb，依照說明下載地震資料。
  2. 使用 Python 處理下載的 MiniSeed 檔案。
  3. 進行資料分析或機器學習偵測。
