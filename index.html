專案簡介

本專案提供地震資料自動下載、處理與深度學習模型（CNN、RNN）分類與偵測流程。
你可以在本倉庫找到 Python 筆記本、訓練腳本、模型成果與波形圖檔。

波形資料展示

  • 原始波形圖檔：Code/Outputs/0130_waveforms/、0611_waveforms/、0827_waveforms/ 等資料夾，包含多台站多通道波形圖。
  • 每個台站如 ALS_HLZ.png、ANP_HLE.png 等，展示地震事件波形。

主要程式與模型

  • Code/00_1Dcnn.py：一維卷積神經網路訓練
  • Code/03_DLrnn_valid.py：RNN 驗證腳本
  • Code/05_Improve_1Dcnn_valid.py：改良版 CNN 驗證
  • Code/Ipynb/：Jupyter 筆記本，包含訓練、測試、資料分析流程
  • Code/1Dcnn.pth、Code/1Drnn.pth：模型權重檔案

如何使用

  1. 瀏覽 Ipynb/ 目錄下的 Jupyter 筆記本，了解訓練與測試流程。
  2. 執行 Python 腳本進行模型訓練與驗證。
  3. 比較不同模型的混淆矩陣與波形分類成果。
